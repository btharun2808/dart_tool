# Measures Converter

Measures Converter is a Flutter app for converting common distance and weight units. It supports metric and imperial units and updates the result as the value or units change.

## Run locally

1. Install the [Flutter SDK](https://docs.flutter.dev/get-started/install).
2. Run `flutter pub get`.
3. Run `flutter run -d chrome` to test the app in Chrome.
