  # Dart tool

Measure Mate is a Flutter conversion app for common distance and weight units. It supports metric and imperial conversions, instant recalculation, and swapping the source and destination units.

## Run locally

1. Install the [Flutter SDK](https://docs.flutter.dev/get-started/install) and an Android emulator or physical device.
2. From this directory, run `flutter create .` to generate the platform runner files.
3. Run `flutter pub get`.
4. Run `flutter run`.
